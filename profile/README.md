# Jig Smiths

A jig is a tool that holds work in place while you shape it, and a jig smith is someone who makes them. Jig Smiths builds small tools that do one job well.

## Projects

- [**brw**](https://github.com/jigsmiths/brw): a Homebrew-compatible package client. It reads Homebrew's metadata and bottles and shares a prefix with `brew`. Early, but install, upgrade, uninstall and cleanup already work for bottled formulae.
- [**dredge**](https://github.com/jigsmiths/dredge): download singles, albums and Spotify playlists as FLAC.
